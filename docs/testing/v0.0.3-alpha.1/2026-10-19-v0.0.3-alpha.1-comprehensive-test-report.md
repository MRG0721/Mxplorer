## 9. 发现并修复的问题

### 9.1 递归复制失败留下部分目标树

- **等级**：高（数据安全/失败原子性）
- **现象**：
  - 不可读目录作为复制根时返回 1，但留下空目标目录；
  - 树中较晚遇到不可读子目录时，目标位置保留已复制前缀。
- **原因**：目标目录在读取源目录之前创建，后续失败没有回滚。
- **修复**：新目录目标先写入隐藏同级 staging 树，成功后 `rename()`；失败、
  取消或最终改名失败时清理 staging。
- **边界**：已存在目标目录继续保持 cp(1) 式合并，合并过程不是事务。
- **回归**：`core_operations` 目录取消检查、`cli_smoke` 根目录/混合子树失败检查。

### 9.2 单个大文件内容检索取消延迟

- **等级**：中（响应性）
- **现象**：取消检查只在条目之间，扫描超大文件时要等文件结束。
- **修复**：`file_contains()` 每 64 KiB 检查取消令牌。
- **回归**：`core_search` 确定性取消测试；8 GiB 文件 SIGINT 实测即时返回。

### 9.3 目录迭代中途错误被当成部分成功

- **等级**：中（正确性）
- **现象**：`directory_iterator::increment()` 报错时直接 `break`，返回已读取条目。
- **修复**：改为返回对应文件系统错误。
- **回归**：该场景难以用普通本地文件系统稳定注入，已通过代码审查和构建/回归矩阵
  验证；暂无自动化故障注入用例。

## 10. 未覆盖范围与已知限制

1. 未重新执行 Debian 7.11、8.11、9.13、11.11、13.7 和 forky/sid 的完整
   deb/tar 兼容性矩阵；这些结果属于 0.0.2-alpha.3。
